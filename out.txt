2. Existing Problem / Current Situation
Describe the real-world problem or gap as it exists today. What currently happens, and where does it fall short?
Modern CI/CD systems handle multiple pipelines containing dependent tasks that may need to share a limited number of runners. Tasks must be executed in the correct order, while independent tasks can run in parallel. Efficiently managing dependencies, resources, and runner availability can become complex.
3. Who Is Affected
Briefly name the affected users/groups. (Full stakeholder detail belongs in the separate Stakeholder Analysis document.)
Software developers, DevOps engineers, development teams, and organizations
 that run multiple CI/CD pipelines and need efficient task execution and resource utilization.
4. Why the Existing Approach Is Inadequate
Explain specifically what is missing, slow, error-prone, manual, or unreliable about the current approach.
Existing CI/CD platforms provide scheduling and execution capabilities, but their internal scheduling logic is generally abstracted from users and is not designed as a configurable environment for studying and comparing scheduling strategies. This makes it difficult to experiment with different scheduling approaches and resource constraints.
This wording is important because we're 
not claiming GitHub Actions/Jenkins are inadequate in real-world use
. They already provide scheduling capabilities. For your project, the gap is the ability to 
experiment with and evaluate scheduling strategies
.

1. Current Process — Narrative Summary
Describe, in plain language, how the process/task is currently carried out from start to finish.
Developers create a CI/CD pipeline by defining tasks and their dependencies. When the pipeline is triggered, the CI/CD platform identifies tasks that are ready to run and assigns them to available runners. Dependent tasks wait until their required tasks are completed, while independent tasks may run in parallel. The platform then updates task statuses and continues until the pipeline is completed.
